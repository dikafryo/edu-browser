# edu-browser

교육청·학교 업무를 돕는 **한 쌍의 프로그램**입니다.

| 폴더 | 프로그램 | 하는 일 |
|---|---|---|
| [`pen-browser/`](pen-browser/) | **PEN 브라우저** (크롬 확장) | 업무 사이트 바로가기 · K-에듀파인 결재대기/공람대기 목록 정리(표를 그대로 읽음, 공람은 AI가 중요도 판단) · 연 공문 분석(마감일·할 일) · **나이스 근무상황(연가·병가·외출 등)·출장 신청 창 자동 채우기** |
| [`gongmun-helper/`](gongmun-helper/) | **공문작성 도우미** (윈도우 프로그램) | K-에듀파인 공문 작성 창에 AI 초안·제목·본문·결재선·과제카드·수신처를 넣어 줌 |

크롬 확장은 크롬 밖 프로그램(K-에듀파인 공문 작성 창)에 손댈 수 없어서, 그 일은 공문작성 도우미가 맡습니다. 두 프로그램은 같은 PC 안에서만 서로 연결됩니다.

## 설치

1. **PEN 브라우저**: 크롬 주소창에 `chrome://extensions` → 오른쪽 위 *개발자 모드* 켜기 → *압축해제된 확장 프로그램을 로드합니다* → `pen-browser` 폴더 선택. 자세한 내용은 [`pen-browser/설치방법.txt`](pen-browser/설치방법.txt).
2. **공문작성 도우미**: `gongmun-helper\실행.bat` 더블클릭 (처음 한 번은 필요한 프로그램을 설치하느라 1~2분 걸립니다. Python 3 가 필요합니다).

## 무엇을 자동으로 해 주나요

| 하는 일 | 어디서 | 사람이 할 일 |
|---|---|---|
| 업무포털·나이스·K-에듀파인 탭 오가기 | PEN 브라우저 | 버튼 누르기 |
| 결재대기·공람대기 목록 정리, 새 문서·긴급 표시 | PEN 브라우저 | K-에듀파인 목록 화면 열어 두기 |
| 공람 중 내 업무와 관련된 문서 고르기 | PEN 브라우저 + 내 AI | 결과 확인 |
| 연 공문의 마감일·할 일 정리, 회신 공문 요청 넘기기 | PEN 브라우저 + 내 AI | 결과 확인 |
| 나이스 근무상황·출장 신청 창 열고 칸 채우기 | PEN 브라우저 | 내용 확인 후 **[승인요청]** |
| 공문 AI 초안, 제목·본문·결재선·과제카드·수신처 넣기 | 공문작성 도우미 + 내 AI | 내용 확인 후 **저장·상신** |

## 꼭 알아 둘 점

- 두 프로그램 모두 **저장·상신·신청 버튼은 누르지 않습니다.** 입력된 내용을 눈으로 확인한 뒤 직접 누르세요.
- 공문 내용은 내 Ollama(또는 교육청 PenGPT)로만 보냅니다. 외부 상용 AI 로 보내지 않습니다.
- 학생·학부모 개인정보는 입력하지 마세요.
- K-에듀파인이 '자동저장문서를 읽어오시겠습니까?' 같은 안내창을 띄우면 도우미는 멈추고 알려 줍니다. 안내창에 직접 답한 뒤 다시 누르세요.

## 시험 (개발용)

```powershell
cd gongmun-helper; .\venv\Scripts\python -m unittest discover -s tests
python tests\pen-browser\run.py
```
