교직원 업무도우미

AI 확인 중… 공문헬퍼 확인 중…

사용 방법

  1. 업무포털에 로그인해 둡니다. 나이스·K-에듀파인 창은 교직원 업무도우미가 업무포털 메뉴를 눌러 직접 엽니다.
  2. 처음 한 번: 설정에서 내 담당 업무를 적고 AI(자체 AI 서버 또는 PenGPT)를 고른 뒤 설정 저장을 누릅니다.
  3. 나이스: 근무상황(연가·병가·외출 등)이나 출장 내용을 적고 나이스 신청 창에 넣기를 누르면, 나이스 창을 열고 신청 창의 칸을 채웁니다. 확인 후 승인요청을 누르면 상신 화면까지 진행해 개인결재선을 골라 둡니다(처음 한 번 설정에서 연가·조퇴·외출·출장·종일출장·연수별 결재선을 골라 두세요). [상신]은 직접 누르세요.
  4. K-에듀파인: 결재대기·공람대기 목록 화면을 띄우고 점검 버튼을 누르면 새 문서·긴급·확인 필요 문서를 골라 줍니다. 공문을 열어 두고 지금 연 공문 분석을 누르면 마감일과 할 일을 알려 줍니다.
  5. 공문 작성은 같은 PC의 공문헬퍼(공문작성 도우미, 아래 설치 방법 참고)가 맡습니다. K-에듀파인 메뉴에서 어떤 공문인지 적고 공문작성 도우미로 보내기를 누르면 도우미 창이 앞으로 나옵니다.
  6. 자동 입력이 끝나면 화면에서 내용을 눈으로 확인한 뒤 직접 저장·상신합니다. 두 프로그램 모두 상신·저장 버튼은 누르지 않습니다(나이스 승인요청은 패널의 버튼을 눌렀을 때만 대신 누름).
공문헬퍼(공문작성 도우미) 설치 방법

공문헬퍼는 K-에듀파인 공문 작성 창(크롬 밖 프로그램)에 AI 초안·제목·본문·결재선·과제카드·수신처를 넣어 주는 PC 프로그램입니다. 공문 작성 기능을 쓸 때만 설치하면 됩니다.

  1. 파이썬 설치(처음 한 번): python.org에서 Python 3를 받아 설치합니다. 설치 첫 화면 아래의 Add python.exe to PATH에 꼭 체크하세요.
  2. 공문헬퍼 받기: https://neis.me/data/gongmun-helper.zip 을 내려받습니다.
  3. 압축 풀기: 받은 파일을 오른쪽 클릭 → 압축 풀기로 내 문서 등 원하는 곳에 풉니다. gongmun-helper 폴더가 생깁니다.
  4. 실행: 그 폴더의 실행.bat을 더블클릭합니다. 처음 한 번은 필요한 프로그램을 설치하느라 1~2분 걸립니다(인터넷 필요).
  5. 연결 확인: 이 패널 오른쪽 위에 공문헬퍼 v…가 초록색으로 보이면 연결된 것입니다. 다음부터는 실행.bat만 더블클릭하면 됩니다.

새 판으로 바꿀 때는 새로 받은 압축 파일을 같은 곳에 풀어 덮어쓰면 됩니다. 결재선 등 설정은 data 폴더에 남습니다. 설치가 실패하면 venv 폴더를 지우고 다시 실행.bat을 누르세요.

오른쪽 위 표시: AI 연결됨은 설정한 AI가 답할 수 있다는 뜻, 공문헬퍼 v…는 공문작성 도우미(공문헬퍼)가 켜져 연결됐다는 뜻입니다.

나이스 복무·출장 입력

업무포털에 로그인해 두고 적은 뒤 누르면, 업무포털 메뉴의 나이스를 눌러 창을 열고 신청 창의 칸을 채웁니다. 채운 내용을 나이스 화면에서 확인한 뒤 [승인요청]을 누르면 승인요청을 대신 누르고, 상신 화면에서 그 복무 종류(연가·조퇴·외출·출장·종일출장·연수)에 맞는 설정의 개인결재선까지 골라 둡니다. [상신]은 직접 누르세요.

복무규정의 연가 사유 호수입니다. 해당 없으면 비워 두세요.

시각은 24시간제(예: 오후 2시 = 14:00), 분은 5분 단위입니다. 반일연가·반일병가는 신청시간과 관계없이 4시간이 차감됩니다.

    결재·공람 점검

    K-에듀파인 결재대기·공람대기 목록 화면을 띄운 뒤 버튼을 누르세요. 목록은 화면의 표를 그대로 읽고, 공람 중 내가 꼭 볼 문서는 설정에서 고른 AI가 제목만 보고 골라 줍니다. 공문 분석은 가장 나중에 연 공문 창을 읽습니다.

    결재(긴급) 목록 화면에서 결재할 문서 점검, 공람 목록 화면에서 공람 문서 점검, 공문을 열어 둔 화면에서 지금 연 공문 분석을 누르면 결과가 여기에 나옵니다.

        공문 작성 → 공문작성 도우미

        K-에듀파인 공문 작성 창은 크롬 밖 프로그램이라, 같은 PC의 공문작성 도우미가 AI 초안과 제목·본문·결재선·과제카드·수신처 입력을 맡습니다. 여기에 적고 보내면 도우미 창이 앞으로 나옵니다.

        날짜·장소·대상, 관련 근거, 붙임을 함께 적으면 됩니다. 내용은 이 PC 안의 공문작성 도우미로만 가며, 학생·학부모 개인정보는 넣지 마세요.

        설정

        공람 문서 중 내가 꼭 확인할 것을 AI가 고를 때 이 기준을 씁니다. 쉼표로 구분해 적으세요.

        나이스 승인요청

        나이스 상신함 > 개인결재선 등록의 결재선 이름을 읽어 옵니다. 직접 적어도 되고, [승인요청]으로 상신 화면이 한 번 열려도 나이스의 목록을 읽어 저절로 채웁니다.

        복무 종류별 결재선

        보통 조퇴·외출·출장은 한 결재선, 연가·종일출장은 다른 결재선을 씁니다. 지각은 조퇴, 병가·공가·특별휴가는 연가 결재선을 따릅니다. 종일출장은 하루를 넘기거나 7시간 이상인 출장입니다.

        보통은 나이스에 등록된 번호를 그대로 씁니다. 출장·연가 등 신청 창의 연락처가 비어 있을 때만 이 번호를 넣습니다(연가·조퇴 등은 비워 둬도 신청됩니다). 이 PC 안에만 저장됩니다.

        AI 연결

        AI 연결 방식

        PenGPT는 연결용 주소(API)가 없어서, 열어 둔 PenGPT 탭에 질문을 대신 넣고 답을 읽어 옵니다. PenGPT에 로그인한 탭을 닫지 마세요. 질문할 때마다 PenGPT 화면에 대화가 하나씩 쌓입니다.

        처음 한 번: PenGPT 탭을 연 뒤 아래 위치 지정을 누르고, PenGPT 화면에서 그 부분을 한 번 클릭하세요. '대화 내용이 나오는 영역'은 질문과 답이 쌓이는 큰 칸(빈 곳)을 클릭합니다.

        Tailscale 이름(mac.○○.ts.net) 대신 100.으로 시작하는 IP를 쓰세요. 이름으로는 Ollama가 접속을 막습니다.

        자체 AI 서버(맥북 Ollama) 준비 방법
        1. 맥북 터미널에서 아래 두 줄을 실행해 확장 프로그램의 접속을 허용합니다. 
          launchctl setenv OLLAMA_ORIGINS "chrome-extension://*"
launchctl setenv OLLAMA_HOST "0.0.0.0"
        2. 메뉴 막대의 Ollama 아이콘에서 Quit 후 Ollama를 다시 실행합니다. (맥북을 재부팅하면 1번을 다시 해야 합니다.)
        3. 한국어 공문을 잘 읽고 쓰는 모델을 받습니다. 지금 있는 translategemma는 번역 전용이라 맞지 않습니다. 
          ollama pull gemma3:12b
          맥북 메모리가 16GB 이하이면 대신 exaone3.5:7.8b를 받으세요.

        공문작성 도우미의 AI도 ⚙ 목록·AI 설정에서 자체 AI 서버와 PenGPT 중에 고릅니다. 도우미에서 PenGPT를 고르면 이 패널이 열려 있는 동안 위 PenGPT 위치 지정을 그대로 써서 대신 묻습니다.

        문제 진단

        새 창(공문 열람 등)을 인식하지 못하거나 공문작성 도우미로 보내지지 않을 때, 그 창을 열어 둔 채 아래 버튼을 누르세요. 창·화면 구조와 도우미 연결 상태만 적으며 공문 내용은 읽지 않습니다. 나이스 상신 화면에서 결재선을 고르지 못하면 그 화면을 띄운 채 NEIS 화면 구조 점검을 누르세요. 공문작성 도우미가 크롬에서 나의 결재선·과제카드를 못 가져오면, 그 목록이 보이는 K-에듀파인 화면을 띄운 채 K-에듀파인 화면 구조 점검을 누르세요.
