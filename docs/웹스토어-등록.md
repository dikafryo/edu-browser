# 크롬 웹스토어 등록 안내 (교직원 업무도우미)

## 준비물

| 무엇 | 어디서 |
|---|---|
| 확장 묶음 | `python tools/make_dist.py` → `dist/교직원업무도우미-웹스토어-v{버전}.zip` (manifest 의 `key` 를 뺀 판) |
| 아이콘 128×128 | `pen-browser/icons/icon128.png` (묶음에 들어 있음) |
| 스크린샷 1장 이상 | 1280×800 또는 640×400 PNG/JPG. 패널의 사용 방법·나이스·K-에듀파인 탭을 찍되 **실명·학교명·전화번호가 보이지 않게** |
| 개인정보처리방침 주소 | `docs/privacy.html` 을 neis.me 등에 올린 주소 (예: `https://neis.me/privacy/edu-helper.html`) |
| 개발자 계정 | https://chrome.google.com/webstore/devconsole — 처음 한 번 등록비 5달러, 본인이 직접 결제 |

## 등록 순서

1. 개발자 대시보드 → **새 항목** → 확장 묶음 zip 을 올린다.
2. **스토어 등록정보** 탭에 아래 글을 붙여 넣고, 카테고리는 '생산성 > 업무 도구'(Productivity), 언어는 한국어.
3. **개인정보 보호** 탭에 단일 목적·권한 이유·데이터 사용을 아래대로 적는다.
4. **배포** 탭: 공개 범위 '공개'(누구나 검색) 또는 '목록에 없음'(주소를 아는 사람만). 처음에는 '목록에 없음'으로 올려 몇 분이 써 본 뒤 공개로 바꾸는 것을 권한다.
5. **검토 제출**. '모든 사이트 접근' 권한 때문에 검토가 며칠~몇 주 걸릴 수 있다.
6. 게시되면 대시보드에 나오는 **항목 ID**(32자)를 `gongmun-helper/gongmun/config.py` 의 `PEN_BROWSER_EXTENSION_IDS` 에 더하고 공문헬퍼를 새로 배포한다. 공문헬퍼는 알려진 확장 ID 의 요청만 받으므로, 이걸 빼먹으면 웹스토어 판은 '공문헬퍼 꺼짐'으로 보인다.

## 스토어 등록정보 글

**이름**: 교직원 업무도우미

**짧은 설명** (132자 이내, manifest 의 description 과 같음):
교직원 업무 보조: 업무포털에서 나이스·K-에듀파인 열기, 결재·공람 점검, 나이스 복무·출장 입력, 공문헬퍼 연결

**자세한 설명**:

```
학교·교육청 교직원이 업무포털, 나이스, K-에듀파인에서 반복하는 일을 줄여 주는 옆 패널입니다.
※ 교육청·나이스·K-에듀파인 운영 기관이 만든 공식 프로그램이 아닌, 개인이 만든 업무 보조 도구입니다.

[나이스]
- 연가·조퇴·외출·출장 내용을 적고 버튼을 누르면 나이스 신청 창을 열어 칸을 채웁니다.
- [승인요청]을 누르면 상신 화면까지 진행하고, 복무 종류별로 정해 둔 개인결재선을 지정해 둡니다.
- [상신]은 항상 사용자가 직접 누릅니다.

[K-에듀파인]
- 결재대기·공람대기 목록에서 새 문서·긴급·확인이 필요한 문서를 골라 줍니다.
- 열어 둔 공문을 AI로 분석해 마감일과 할 일을 알려 줍니다(사용자가 정한 AI만 사용).

[공문헬퍼 연결]
- 같은 PC의 공문헬퍼(공문작성 도우미)와 연결해 공문 작성 창에 초안·결재선·과제카드를 넣습니다.
- 공문헬퍼 설치 방법은 패널의 [사용 방법]에 있습니다.

[개인정보]
- 설정과 입력값은 이 PC의 크롬 안에만 저장됩니다. 개발자에게 보내는 정보는 없습니다.
- 공문 내용은 사용자가 설정에서 고른 AI(직접 운영하는 AI 서버 또는 PenGPT)에만 보냅니다.
```

## 개인정보 보호 탭

**단일 목적**:
교직원이 업무포털·나이스·K-에듀파인에서 하는 업무(복무 신청, 결재·공람 확인, 공문 작성 준비)를 옆 패널에서 보조합니다.

**권한 이유**:

| 권한 | 이유 |
|---|---|
| sidePanel | 업무 보조 화면을 브라우저 옆 패널로 보여 줍니다. |
| storage | 사용자 설정(담당 업무, AI 주소, 결재선 이름 등)을 사용자 PC 안에 저장합니다. |
| tabs | 업무포털에서 나이스·K-에듀파인 창을 열고, 열린 창을 찾아 패널의 작업을 이어 갑니다. |
| scripting | 사용자가 버튼을 누르면 나이스 신청 창의 칸을 채우고, K-에듀파인 목록·공문 내용을 읽습니다. |
| alarms | 확장 프로그램이 새 판으로 바뀌었는지 주기적으로 확인합니다. |
| 호스트 권한 (모든 사이트) | 업무포털·나이스·K-에듀파인 주소가 17개 시도교육청마다 다르고, 사용자가 직접 정하는 AI 서버 주소에도 접속해야 해서 특정 주소로 제한할 수 없습니다. 사용자가 버튼을 누를 때에만 해당 화면에 접근합니다. |

**원격 코드 사용**: 아니요 (모든 코드는 묶음 안에 있음)

**데이터 사용** 체크:
- 수집하는 데이터: '웹사이트 콘텐츠'(공문 본문을 사용자가 정한 AI로 보낼 때), '개인 식별 정보'(사용자가 적은 비상연락처를 나이스 신청 칸에 넣을 때 — PC 안에만 저장) 정도로 체크하고 아래 세 가지 확인란에 모두 동의
  - 승인된 사용 사례 외에 제3자에게 판매·전송하지 않음
  - 핵심 기능과 무관한 목적으로 사용·전송하지 않음
  - 신용도 판단·대출 목적으로 사용·전송하지 않음
- 개인정보처리방침 URL: 위에서 올린 privacy.html 주소

## 주의할 점

- **이름의 '교육청'**: 웹스토어는 공공기관을 사칭하는 것처럼 보이는 이름을 거절할 수 있다. 설명 첫머리의 "공식 프로그램이 아님" 문구를 빼지 말 것. 거절되면 '교직원 업무도우미'처럼 바꾸는 것을 고려한다.
- **확장 ID**: 웹스토어 판은 지금 압축해제로 설치한 판과 ID 가 다르다. 둘 다 설치하면 패널이 두 개 생기므로 웹스토어 판을 설치한 뒤 압축해제 판은 지운다. 설정은 옮겨지지 않는다(설정 탭에서 다시 적기).
- **새 판 올리기**: manifest 의 version 을 올리고 `make_dist.py` 로 다시 묶어 대시보드의 '패키지 > 새 패키지 업로드'로 올린다. 사용자 크롬은 검토가 끝나면 저절로 새 판을 받는다.
